🗄️ DATABASE SCHEMA (Room)

Table: wallpaper_history

```kotlin
@Entity(tableName = "wallpaper_history")
data class WallpaperEntity(
    @PrimaryKey(autoGenerate = true)
    val id: Long = 0,
    val imagePath: String,              // Local storage path
    val thumbnailPath: String,          // Compressed thumbnail
    val dateSet: Long,                  // Timestamp
    val isFavorite: Boolean = false,
    val isPDF: Boolean = false,
    val pdfPageNumber: Int = 0,
    val pdfTotalPages: Int = 0,
    val pdfRotation: Int = 0,           // 0, 90, 180, 270
    val brightness: Float = 1.0f,
    val contrast: Float = 1.0f,
    val saturation: Float = 1.0f,
    val vignette: Float = 0.0f,
    val textOverlay: String?,           // Custom quote
    val textAuthor: String?,            // Author name
    val textColor: String = "#FFFFFF",
    val textSize: String = "Medium",
    val textPosition: String = "Center",
    val fontStyle: String = "Poppins",
    val cropRatio: String = "16:9"
)
```

Table: schedules

```kotlin
@Entity(tableName = "schedules")
data class ScheduleEntity(
    @PrimaryKey(autoGenerate = true)
    val id: Long = 0,
    val time: String,                   // "08:00"
    val days: String,                   // "Mon,Wed,Fri" or "Daily"
    val wallpaperId: Long,              // Reference to wallpaper_history
    val isActive: Boolean = true,
    val label: String?                  // "Morning", "Focus", etc.
)
```
