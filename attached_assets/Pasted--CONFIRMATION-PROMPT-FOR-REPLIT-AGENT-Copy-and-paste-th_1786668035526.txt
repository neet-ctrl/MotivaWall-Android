Release Build (Minimal Time)

☐ Runs on push to main branch
☐ Uses JDK 17
☐ Only builds arm64-v8a ABI
☐ No lint checks (skip for speed)
☐ No unnecessary tasks
☐ Signs APK with JKS file
☐ Keystore: app/keystore.jks
☐ Password: Sh@090609
☐ Alias: my-key
☐ Hardcoded credentials (no secrets)
☐ Creates GitHub Release
☐ Uploads APK to release
☐ Workflow time: < 5 minutes

Workflow YAML Structure

```yaml
name: Build & Release

on:
  push:
    branches: [ main ]

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: actions/setup-java@v3
        with:
          java-version: '17'
          distribution: 'temurin'
      - name: Build APK
        run: |
          chmod +x gradlew
          ./gradlew assembleRelease --no-daemon -Pandroid.injected.build.abi=arm64-v8a
      - name: Sign APK
        run: |
          # Sign using hardcoded keystore
          jarsigner -verbose -sigalg SHA1withRSA -digestalg SHA1 \
            -keystore app/keystore.jks -storepass Sh@090609 \
            -keypass Sh@090609 -alias my-key \
            app/build/outputs/apk/release/app-release-unsigned.apk
          # Align APK
          zipalign -v -p 4 app/build/outputs/apk/release/app-release-unsigned.apk \
            app/build/outputs/apk/release/app-release.apk
      - name: Create Release
        id: create_release
        uses: actions/create-release@v1
        with:
          tag_name: v1.0.0
          release_name: MotivaWall v1.0.0
          draft: false
          prerelease: false
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
      - name: Upload APK
        uses: actions/upload-release-asset@v1
        with:
          upload_url: ${{ steps.create_release.outputs.upload_url }}
          asset_path: app/build/outputs/apk/release/app-release.apk
          asset_name: MotivaWall-v1.0.0-arm64-v8a.apk
          asset_content_type: application/vnd.android.package-archive
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```
